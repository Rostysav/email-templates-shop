Start here

Two files: a welcome email and a packing slip. Same mark and accent as Brand Ops Pack — so if you upgrade later, everything still matches.

1. Preview

Open index.html, then click Welcome or Packing slip. Or use the live preview: rostysav.github.io/email-templates-shop

2. Welcome email

  1. Open emails/welcome.html in a browser.
  2. Replace Quill name, offer text, and the discount code.
  3. Point every href="#" to your real URLs / ESP tags.
  4. Copy the HTML into Shopify Email, Klaviyo, or Omnisend → send a test to Gmail + Outlook.

3. Packing slip

  1. Shopify Liquid: open packing/packing-slip.liquid, copy all, paste into Settings → Shipping and delivery → Packing slips.
  2. Print preview: open packing/packing-slip.html → Print → Save as PDF, or print on letter paper.
