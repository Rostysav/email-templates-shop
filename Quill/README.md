# Quill email templates

Seventeen light HTML emails for a Shopify store, from welcome through the order, after delivery, a sale, and a product drop. Names, prices, the Greene Street address, and the codes are examples. Replace them before you send.

Open `emails/index.html` for the letters and `cards/index.html` for the packing cards. Those pages are only local previews. Do not email them or put them in a parcel.

Each letter uses table layout and inline CSS for Gmail, Apple Mail, Outlook, Yahoo, and mobile. The colors are locked so a dark-mode inbox does not invert them.

## Brand

Mark: letter `Q` in a box, then `QUILL`. Accent `#9B2F1E`. Example products: The Oak Desk Lamp ($220), The Ink Set ($48). Customer Owen Hart. Store 110 Greene Street, New York, NY 10012. Codes `QUILL10`, `QUILL15`, `QUILL`, `AGAIN`.

Every link is `href="#"`. Photo areas use placehold.co — replace with your own hosted files before a live send.

## Packing cards

In `cards/`: a welcome card, a thank-you card, and a return insert. Open each file and print at **5 × 7 in**. They are not wired to an order — print a stack and put one in the box.
