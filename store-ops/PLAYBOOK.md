# Daily playbook (10:00 and 18:00)

## Goal

Grow the Gumroad email-template shop: keep listings healthy, ship new templates when demand is clear, and promote with useful engagement — not spam.

## Every run

1. **Gumroad**
   - Open the shop; check published products (Quill live; Ash and others as noted in `products-catalog.md`).
   - Fix broken previews, missing cover images, weak titles/descriptions, wrong prices.
   - Note sales/views if visible; update `products-catalog.md`.
2. **New products**
   - Only add a product when there is a clear niche gap or trend (see `content-ideas.md`).
   - Prefer HTML email template packs in this repo (same quality bar as Quill).
   - Draft listing copy before publishing; do not publish half-finished packs.
3. **Social — replies first**
   - LinkedIn, X, Reddit: check notifications for replies to our posts/comments; answer helpfully.
4. **Social — outbound comments**
   - Comment on niche posts (email marketing, Shopify, ecommerce, creator tools).
   - Add value first; soft mention of templates only when it naturally fits.
5. **Log**
   - Append 5–10 lines to `logs/YYYY-MM-DD.md`: what checked, what posted/commented, what changed in the shop.

## Time focus

| Run | Focus |
| --- | --- |
| **10:00** | Shop health + product work + LinkedIn/X engagement |
| **18:00** | Replies, Reddit/X engagement, content ideas for next day |

## Hard rules

- No mass identical comments.
- No fake engagement / bots / purchased traffic.
- Reddit: no direct Gumroad links in comments unless the subreddit allows promo and the reply is clearly helpful first. Prefer value-only comments.
- Do not delete or overwrite existing product source without a clear reason.
- Do not commit secrets, passwords, or payment details.
- If a platform blocks or rate-limits, stop that platform and note it in the log.
